## 2. 完整描述（4000 字符内，首发版）

Fitness Pro 是一款本地优先的力量训练记录应用。

【训练中】
- 按计划逐组记录：重量、次数、时长、距离、左右分离次数、RPE
- 上次成绩自动回显与预填，双进阶（加重/维持/减重）建议只提示、不替你做决定
- 组间休息倒计时走系统通知，锁屏、切应用、杀进程都不影响计时
- 破纪录（最大重量 / 单组容量 / 估算 1RM）即时庆祝，不打断记录节奏

【训练后】
- 总结页展示容量、组数、总次数，与上一次同一计划对比
- 训练历史、容量趋势、肌群分布、日历热力图
- 个人纪录榜与动作趋势

【数据属于你】
- 无账号、无上传、无广告。所有数据只保存在这台手机上
- 一键导出完整备份（含全部媒体），换机恢复零丢失
- 可选读取 Health Connect 的体重数据（唯一的外部数据源，需你明确授权）

【适合谁】
- 用杠铃/哑铃/器械做系统训练的人
- 关心"这次比上次进步了吗"，而不是社交与打卡
- 在意隐私、不想把训练数据交给云服务的人

## 4. 权限与数据安全表单（Play Data Safety 如实填写）

| 权限/数据 | 用途 | 是否上传 |
|---|---|---|
| POST_NOTIFICATIONS | 休息倒计时与每日训练提醒 | 否（本地） |
| android.permission.health.READ_WEIGHT | 读 Health Connect 体重，仅写入本地身体数据页 | 否（本地） |
| VIBRATE | 休息结束震动 | 否（本地） |
| RECEIVE_BOOT_COMPLETED | 重启后清理过期的休息计时状态 | 否（本地） |
| INTERNET / ACCESS_NETWORK_STATE | 仅系统组件依赖；应用本体不联网 | 否（本地） |

Data Safety 表单结论：不收集、不共享任何用户数据。应用无任何分析 SDK、无崩溃上报云服务
（崩溃日志仅在本机文件系统，仅当用户在设置中显式开启时记录）。
